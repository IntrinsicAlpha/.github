Intrinsic Alpha builds stock valuation and research tools for self-directed investors. Explore discounted cash flow (DCF) models, review the assumptions behind an estimate, and compare financial results for U.S.-listed companies.

## Open source

[**Intrinsic Alpha Skills**](https://github.com/IntrinsicAlpha/skills) is an MIT-licensed agent skill with plugins and setup guides for connecting to Intrinsic Alpha from Claude, ChatGPT, Codex, and other MCP clients. Use it to pull financial statements, compare peers, review valuation estimates, and chart financial history. A free Intrinsic Alpha account can connect to the hosted MCP server.

```sh
npx skills add IntrinsicAlpha/skills
```
